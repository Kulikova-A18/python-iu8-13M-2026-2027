# Улучшение кода из задания dz-3

> Задание связано с [dz-3](https://github.com/Kulikova-A18/python-iu8-13M-2026-2027/tree/main/dz-3)

В ходе анализа кода мы выявили, что наш код не такой и печальный, но внимательные заметили что рядом лежат методы атак.

Необходимо:

* Обезопасить код с информацией из dz-3
* Обезопасить код от различных методик атак
* Добавить логирование
* Запустить сервер через docker
* Проверить свой код и docker через semgrep

> Не забываем об [semgrep-rules/dockerfile](https://github.com/semgrep/semgrep-rules/tree/develop/dockerfile)
